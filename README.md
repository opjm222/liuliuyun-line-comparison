## 六六云是什么来路，靠不靠谱

六六云是 2020 年成立的国人商家，主营海外原生 IP VPS，节点覆盖香港、日本、韩国、美国、英国、德国、菲律宾七个地区。产品线主打原生 IP、双 ISP 双线归属和精品回程，定位是 TikTok 运营、ChatGPT 访问、跨境电商、海外建站这类对 IP 质量敏感的场景。付款支持支付宝、微信、PayPal，下单后 30 分钟内要完成付款，超时订单自动取消，付完秒级开通，不用等人工审核。控制面板支持自助重装系统、创建快照、VNC 救援。

商家靠不靠谱，第三方给过一个很实在的判断。NodeSeek 上那篇英国双 ISP 测评（2026 年 9 月）是这么写的：

> 商家运营也有一段时间了，主要业务方向是“IP质量不错的VPS”，本身讨论度不高，我们对这个商家知之甚少，如果感兴趣的话建议是先月付来观察其稳定性，没有问题再考虑年付，我们也需要更长的时间来了解商家

“讨论度不高、了解有限”，这句话应该是全文最该记住的一句。六六云不属于那种被大量用户反复验证过的大商家，它更像一个在细分需求上做得还行的中小商家。所以后面所有关于“要不要年付”的建议，都要先经过这一条。

还有一点比价格更影响决策：六六云官网没有一份统一的退款政策，发生争议时基本取决于你买的那款产品页面和下单时的说明。具体到产品上差别很大，美国 NTT 写明 48 小时内不满意可以退款，美国 CN2GIA 的活动机写明“本产品是活动机，请注意无退款”，英国双 ISP 那款则完全没提退款，只能按不可退款来理解。买之前一定要点开自己那一款的产品页看清楚。

## 各条线实测：延迟、路由、IP 质量差在哪

### 香港 CMI：三网真直连，延迟是它的核心竞争力

香港 CMI 这条线的实测数据在资料里最完整。三网延迟大致是这样：

| 测试节点 | 电信 | 联通 | 移动 |
| --- | --- | --- | --- |
| 北京 | 约 40ms | 约 42ms | 约 50ms |
| 上海 | 约 32ms | 约 40ms | 约 38ms |
| 深圳 | 约 10ms | 约 10ms | 约 11ms |

真正值钱的是回程路由。电信回程走 CTG 加 CN2 直连内地，是 CN2 GIA 级别的精品线路；联通回程走 CUG（AS10099 加 AS4837）直连；移动回程走 CMI 直连。三条线各走各的，不是那种“只有移动走 CMI、电信联通绕美国”的假三网优化。晚高峰延迟波动也不大。

HK-CMI-150M 的实测：Speedtest 亚洲节点下载稳定在 140–150Mbps 区间，上传也接近峰值；磁盘 IO 大约 220MB/s；CPU 是 E5-2697A v4 @ 2.60GHz，Geekbench 5 单核约 800 分。

IP 方面，TikTok 识别为香港地区，能正常刷视频、看直播，没有“网络异常”提示；Netflix 港区、Disney+ 可以解锁；Scamalytics 等风控库评分正常，没有被标成机房或代理 IP。这里要说明用词：测评原文写的是“相对干净的香港原生IP”，没有给出住宅 IP 的判断，也没有贴 IP 库原始输出，所以别把它理解成家宽住宅 IP。IP 纯净度本身会随时间变化，新 IP 段通常更干净，六六云会定期补货新段，遇到被标记的情况可以开工单申请换 IP。

这条线不适合的场景也明确：不带高防 DDoS，默认装 Linux，要 Windows 得自己额外配置，500Mbps 以上的超大带宽需求它接不住。

### 美国 NTT：回程直连，去程联通绕了德国

本地 Ping 平均 159ms。全国三网平均 212ms，其中电信 185ms、联通 256ms、移动 205ms。差距藏在去程：电信直连洛杉矶走骨干网，联通绕了德国节点才到洛杉矶、走 AS4837，256ms 就是这么来的，移动经香港、日本节点过去走 CMI 骨干网。三网回程则全部从美国机房直连回国。

海内外一共测了 100 个节点，全部稳定、无丢包。机器是 AMD EPYC 7532 32-Core，磁盘 I/O 172MB/秒，本地下载 10.8MB/秒。

这款最容易被误解的地方是 IP 类型。它给的是机房双 ISP 原生 IP，不是家宽住宅 IP，两者在平台风控眼里的权重不一样。对 IP 类型要求特别严格的业务，测评的建议是先买一台实测，别一上来就批量上。

### 美国 CN2GIA：线路确实好，但这是一台“有前提”的机器

去程电信 CN2、联通 9929、移动 CMIN2，回程三网全是 CN2GIA。线路是 Netlab 采购自 DMIT 的带宽，路由特征与 DMIT 的 Pro 系列相符，所以被戏称为“小妈云”。实际表现：电信基本 130–180ms，三网全天单线程能跑到 200Mbps–300Mbps+。

IP 是 154 开头的 Cogent 段，带伪家宽属性。好的部分是 TikTok US、ChatGPT US、Netflix US、Disney+ US、Gemini US 这些主流美国服务全部识别为美国；IP 锁区，不会送中。差的部分也得摆出来：IPQS 欺诈得分 84、是否机器人 Yes、是否代理 Yes，DNS 黑名单 304 项检查里有 11 项被列黑，Claude、Perplexity AI、Mistral AI 显示 Banned (WAF)，Wikipedia 可编辑性为 NO。性能上，AMD EPYC 7K62、sysbench 单核 1595 分，但 4K 块读写只有约 9.9MB/s，偏弱。

测评原文的风险提示值得原样引用：

> IP虽然现在看起来是比较新的伪家宽IP，质量还不错，但是随着时间的推移线路机的IP段可能会崩坏……虽说是Dmit的Pro线路，但并不是Dmit的官方产品，实际的使用情况和稳定性与Dmit的官方产品相比还需要观察，请谨慎下单！

### 美国 AS4837：便宜是真的，普通线路也是真的

本地（电信线路）延迟 186ms，下载 8.43Mbps，上传 63.10Mbps。回程做了北京、上海、广州、成都四地三网共 12 项检测，全部走联通 AS4837，线路类型一栏统一标注“普通线路”，不是优化回程。买它图的是价格和 IP，不是线路质量。

IP 检测显示为美国原生 IP，多个数据库识别为家宽，但 IP2Location 判断是 IDC 机房 IP —— 这个矛盾测评自己也承认了，标题写“原生家宽双ISP”，正文又写 IP2Location 判 IDC，引用时得带上这个限定。多数库显示低风险、黑名单 0 条，流媒体和 AI 平台大多能解锁并识别为美国。

### 英国双 ISP：已经送中，只能当落地机

直连体验差得很直接。三网勉强能连，电信和移动丢包比较严重，联通稍好。实测数据有三组：一组 200 包测试 10.5% 丢包、平均 265.557ms；一组 1.5% 丢包、平均 290.178ms、最大 396.034ms；较好的一组 172.572ms、0% 丢包。波动大，不建议直连用。

它的正确用法是落地。从德国中转过去延时只有 13.8–16.3ms，能跑满 1Gbps，iPerf3 单线程 945–949Mbits/sec。

机器性能一般，Xeon Gold 6230、sysbench 单核 866 分，4K 块读写只有 9.7/9.9 MB/s，属于“能用”的机器。跑 API、反代、静态博客这类轻量应用可以，重负载别想。

IP 风险测评写得很直白：“此类产品可能会因个人操作不当或者邻居影响存在[送中]风险，目前已经送中，其他IP段也可能存在此风险，我们希望您在购买前知悉此情况”。IP 库那头，信任得分 100，VPN、代理、Tor、匿名、攻击者全部为 No，但使用类型里含 hosting，ipregistry 判断为云提供商。解锁方面 ChatGPT GB、Claude GB、Netflix GB、Disney+ GB、TikTok GB、Prime Video GB 都是 YES，Gemini 是 NO，Google Play Store 显示 CN、YouTube Region 显示 CN、Google 搜索可行性 NO。

## 几个常被问到的问题

### 香港 CMI 能解锁 TikTok 和 ChatGPT 吗？

TikTok 能识别为香港地区，刷视频和看直播都正常，没有“网络异常”提示。流媒体方面 Netflix 港区、Disney+ 可以解锁。IP 在 Scamalytics 这类风控库里评分正常。要注意 IP 纯净度会随时间变化，遇到被标记可以工单申请换 IP。

### 双 ISP 原生 IP 和家宽住宅 IP 是一回事吗？

不是。美国 NTT 那款是机房双 ISP 原生 IP，归属和机房一致，纯净度有保障，但家宽住宅 IP 走的是当地家庭宽带线路，在平台风控眼里权重更高。做跨境电商、自媒体运营够用，业务对 IP 类型要求特别严格的，先买单台实测再决定要不要批量上。

### 标 1000Mbps，实际跑不满是不是虚标？

不是。从国内跨太平洋访问，受国际出口限制，本地带宽跑不满 1000Mbps 是正常现象。实测本地下载 10.8MB/秒，折算下来接近百兆水平。大带宽的意义在机房本地和多线程场景，余量是够的。

### 联通和移动去程绕路，影响大吗？

看用途。SSH 远程管理这类双向流量的操作，绕路会让手感慢一点。实际业务大部分流量走回程，美国 NTT 三网回程都是直连回国，下载和网页加载不受去程影响。

### 第一次买，选月付还是年付？

月付。第三方对这家商家的判断是“讨论度不高、了解有限，建议先月付观察稳定性，没有问题再考虑年付”。年付能省的地方主要在美国 NTT（省 100 元）和活动机，香港三档年付没有任何折扣，没必要提前锁定一年。
